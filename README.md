# RepPlan

**Discipline made visible.** A mobile-first workout split planner and in-gym logger.

## Stack
- **Frontend:** React + Vite + Tailwind CSS, installable PWA
- **Backend:** FastAPI (Python)
- **Database:** Supabase (Postgres)
- **Charts:** Recharts
- **Auth:** Supabase Auth

## Layout
```
backend/     FastAPI app, seed scripts, tests
frontend/    React + Vite PWA
supabase/    SQL migrations & schema
```
